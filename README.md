# ms-bin-catcher-go

Веб-приложение для работы с ячейками склада МойСклад с телефона или ПК прямо из браузера.

## Зачем

Мобильное приложение МойСклад не работает с ячейками. ms-bin-catcher-go закрывает этот пробел:
отсканировал товар — увидел, в каких ячейках он лежит, — поправил расхождение перемещением.

## Возможности (MVP, в разработке)

- Скан штрихкода товара → список ячеек с остатками
- Выбор ячейки из списка с поиском (для складов без маркировки ячеек)
- Перемещение с ячейки на ячейку от имени сотрудника
- Сканеры: камера телефона, USB и Bluetooth (режим HID)

## Стек

Python 3.11+, FastAPI, httpx, pytest · МойСклад JSON API 1.2
